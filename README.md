# 🐍 Snake Game - لعبة الثعبان

لعبة ثعبان كلاسيكية مبنية بـ **HTML5** و **JavaScript**!

## 🎮 العب الآن
[**اللعب المباشر هنا**](https://zakaria731.github.io/snake-game/)

## 🎯 كيفية اللعب
- **⬆️ استخدم الأسهم** أو **الأزرار على الشاشة** للتحكم بالثعبان
- **🔴 اجمع الكرات الحمراء** لتكبير الثعبان وزيادة النقاط
- **⚠️ تجنب الجدران** والاصطدام بنفسك
- **⚡ كل 10 نقاط تصعد مستوى أصعب وأسرع**

## ✨ المميزات
✅ واجهة حديثة وجميلة  
✅ لوغو متحرك  
✅ نظام نقاط والمستويات  
✅ أزرار تحكم على الشاشة  
✅ متوافق مع الهاتف والكمبيوتر  
✅ بدون إعلانات أو تطبيقات

## 📋 المتطلبات
- متصفح حديث فقط (Chrome, Firefox, Safari, Edge)
- لا تحتاج لتثبيت أي شيء!

## 📁 الملفات
- `index.html` - اللعبة الرئيسية (مع واجهة حديثة)
- `snake.html` - النسخة الأصلية

## 🚀 كيفية التشغيل المحلي
1. حمّل الملفات
2. افتح `index.html` في متصفحك
3. ابدأ اللعب! 🎮
